# ─── LABORATOIRE (Analyse chimique + Inspection) ───

mini-games/laboratoire/labo-interieur.webp
  Vue plongeante d’un laboratoire industriel. Étagères métalliques, verres à pied,
  pileuse cassée. Plan de travail central en acier inox éclairé par une lampe bleue.
  Réfrigérateur miniature à gauche, bureau avec un tiroir ouvert (carnet de labo).
  Ambiance froide, bleutée, légèrement inquiétante.

mini-games/laboratoire/verrou-rechaudi.png
  Verrou de port de laboratoire, légèrement brûlé — indice d’un accès forcé.
  Texture métallique, reflet orangé en bas.

# ─── CHRONOS (Manipulation — train de sonnerie) ───

mini-games/chronos/mecanisme-closeup.webp
  Vue en cross-section du cœur du Chronos : engrenages dorés, ressort tendu.
  Cache arrière ouvert (bande magnétique visible). Traces de doigts en poudre.
  Éclairage tamisé, filtré par de la poussière d’âge.

mini-games/chronos/roue-temps.webp
  Roue de temps en or massif, motif Zodiaque. Vue 3/4 avec reflets changeants.
  Arrêtée visuellement sur 23h47 (indexeur subtil).

mini-games/chronos/pince-a-jouet.webp
  Pince à joindre miniaturisée, style horloger. À comparer avec empreinte.

# ─── MONTRE DU DUC (Décodage) ───

mini-games/montre/montre-du-duc-face.webp
  Montre de poche ancienne, gravure florale. Écran brillant ; reflet suggère
  un motif au revers.

mini-games/montre/montre-du-duc-dos.webp
  Revers de la montre : code gravé sous forme de lignes ondulées (3 onglets
  tournants). Texture or terni pour le code.

mini-games/montre/equerre-lumineux.webp
  Équerre lumineuse style steampunk. Active le soulignement du code.

# ─── NOTES DE RÉALISATION ───
# 1. Tous les nouveaux assets doivent être exportés en .webp (moderne, léger) ;
#    sauf les objets manipulables précis (pince, pipsette) en .png (transparence).
# 2. Résolution cible : 800x600 minimum (desktop) ; éviter fichiers > 500 Ko.
# 3. La palette couleur reste dans les tons froids (bleus, gris, or terni) pour
#    rester dans l’atmosphère horlogerie du jeu.
# 4. Aucun texte n’est intégré dans les assets — tout texte dynamique passe par
#    la couche JS/i18n (index.html / script.js) pour le multilingue FR/EN.
